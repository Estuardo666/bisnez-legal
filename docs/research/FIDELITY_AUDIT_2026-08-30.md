# Fidelity audit — Fileon → Meiker

Playwright captures were produced at 1440 × 1000, 768 × 900 and 390 × 844. Source and local pages were scrolled before full-page capture to activate viewport-driven content.

## `/services`

- Source desktop height: 3902 px; Meiker: 5556 px (+42%).
- Source sequence: photographic hero → separate editorial title strip → five compact horizontal service rows → sparse CTA → footer.
- Meiker sequence: photographic hero with overlaid title → feature introduction → large service-card grid → extended services → CTA → FAQ → footer.
- Assessment: visual assets and broad editorial mood are preserved, but section count, hierarchy and density are not pixel-faithful.

## `/contact`

- Source desktop height: 4098 px; revised Meiker: 4029 px (-1.7%).
- Source mobile height: 4710 px; revised Meiker: 4580 px (-2.8%).
- Preserved sequence: image hero → three contact cards → centered testimonial → narrow form → FAQ/office grid → footer.
- Assessment: high structural fidelity with intentional Meiker brand and content substitutions.

## `/teams/amelia-brooks`

- Source desktop height: 3131 px; revised Meiker: 3113 px (-0.6%).
- Source mobile height: 3970 px; revised Meiker: 4103 px (+3.4%).
- Preserved sequence: 574 px hero → offset portrait → compact contact card → long biography/practice body → two credential cards → back action → footer.
- Assessment: high template fidelity; identity and professional content are intentionally mapped to Augusto Abendaño.

## `/services/corporate-legal-advisory-copy-4`

- Source desktop height: 3401 px; Meiker: 3278 px (-3.6%).
- Source mobile height: 4789 px; Meiker: 4313 px (-9.9%).
- Preserved sequence: light navigation → two-column intro → two metrics → long-form text → wide body image → closing text → back button → dark footer.
- Responsive stacking and image ratios follow the source.
- Intentional differences: Geist typography, Meiker palette/copy/logo, supported metrics and Meiker footer.
- Assessment: high structural fidelity with intentional brand substitutions.
