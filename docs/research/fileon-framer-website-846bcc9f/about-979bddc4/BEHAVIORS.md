# Meiker /about — behaviors

- Shared header opens the mobile navigation and the desktop “more” panel; Escape closes open navigation.
- Page links route to `/services`, `/contact`, and `/teams` without external dependencies.
- FAQ rows use native `<details>` disclosure and remain keyboard accessible.
- Cards and CTA links receive a restrained translate/arrow hover state.
- `Reveal` honors `prefers-reduced-motion` and only reveals sections once.
