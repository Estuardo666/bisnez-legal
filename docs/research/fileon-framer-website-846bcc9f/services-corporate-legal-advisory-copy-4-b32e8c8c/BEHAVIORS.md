# Service detail behaviors

- Interaction model: primarily static document flow.
- Navigation menu: click-driven on narrow screens.
- Buttons and navigation links: subtle translate/color hover transition.
- Images: static, no carousel, parallax or layered animation.
- Responsive model: two-column intro above 1024 px; stacked intro below it.
- Reduced-motion QA was used for deterministic screenshots.
- Source screenshots and computed geometry are stored in `raw/*-audit.json` and the matching design-reference directory.
