# Motion Arrow Button behaviors

Source: `https://framer.com/m/Motion-Arrow-Button-a1FUwR.js@z8GhHbPl9FYjHVdU5kMx`

- Interaction model: link/button with hover and pressed gesture states.
- Default intrinsic size: 181 × 56 px.
- Backdrop hover: scale `1 → 1.04`, realistic four-layer shadow, spring duration 0.4 s, bounce 0.
- Pressed backdrop: scale returns to 1 while retaining the hover shadow.
- The icon is constructed from five 4 × 3 px bars arranged in three columns.
- Hover icon layer: opacity `0 → 1`; its five bars scale from `0.2 → 1`.
- Hover icon horizontal anchor: right `31px → 24px`.
- Overall gesture/layout transition: spring duration 1 s, bounce 0.
